To access weather data from OpenWeather, you will first need to register for an account. For this project, I used the One Call API 2.5, which is the free OpenWeather version. Once you’ve registered, OpenWeather will issue you a unique API key, which is will be used as your authentication when making a request to the API. 

Do not hardcode directly into your source code. Store your API key externally, like a .env file, and load it into your application. Ensure to include your .env file to your .gitignore file to ignore the file when you make a commit.
